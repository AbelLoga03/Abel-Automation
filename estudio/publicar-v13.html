3 · Publicación responsable

Cuando hayas revisado manualmente la web y quieras publicarla, puedes usar GitHub Pages para un sitio estático propio. La publicación requiere una cuenta y una decisión expresa; este asistente no realiza cambios en GitHub.

  1. Exporta la web ZIP desde el constructor y extrae su contenido.
  2. Prueba la carpeta en un navegador y verifica todos los enlaces, fotografías y formularios.
  3. Crea un repositorio propio en GitHub y sube los archivos exportados a la raíz de la rama destinada a publicar.
  4. Configura Pages en el repositorio, seleccionando la rama y carpeta pertinentes, y revisa el resultado público.
  5. Comprueba el dominio, HTTPS y privacidad. Si utilizas formularios reales, pagos o reservas, necesitarás integraciones adicionales y revisión legal.

Para la propia web de Abel Automation, el código se publica mediante el repositorio principal y sus comprobaciones; los proyectos de los visitantes no se publican automáticamente.
