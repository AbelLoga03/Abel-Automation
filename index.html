Antes de empezar

Algunas
respuestas.

¿Estas webs ya son proyectos oficiales? +

No. Todas las marcas y productos que ves aquí son inventados. Estas webs sirven para explorar cómo podría funcionar un diseño real, pero no son encargos de clientes.

¿La web funciona desde el móvil? +

Los diseños de muestra se han planteado para ordenador y móvil. Antes de una entrega real habría que validar contenidos, formularios, accesibilidad y funcionamiento con los datos definitivos.

¿Puedo tener una web sin tienda online? +

Sí. Para muchos negocios basta con una web de presentación o un catálogo que permita consultar precios y disponibilidad sin pagos online.

¿Están incluidos el dominio y el mantenimiento? +

No necesariamente. El dominio, el alojamiento, las licencias, cualquier mantenimiento y servicios de terceros se presupuestarían por separado antes de aceptar un proyecto.

¿Qué sucede cuando relleno el formulario? +

Esta es una web de demostración. El formulario genera un texto que puedes copiar o compartir; no guarda tus datos ni envía nada a ningún servidor. Cuando se configure un correo autorizado, podrá abrir un borrador en tu aplicación de correo.
