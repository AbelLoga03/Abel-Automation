# Abel López · Portfolio de diseño web y automatización

Portfolio personal independiente, preparado para GitHub Pages.

## Abrir la página

El archivo de entrada es `index.html`; las cinco demostraciones están en `demos/`.

Cuando GitHub Pages esté activado desde Settings → Pages → Deploy from a branch → main / (root), la dirección prevista será:

https://abelloga03.github.io/Abel-Automation/
